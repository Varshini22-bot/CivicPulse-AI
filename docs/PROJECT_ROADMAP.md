# CivicPulse AI — Future Project Roadmap

## Version History & Accomplished Milestones

### Version 1.0.0 — Production-Grade Web Baseline (Current Release)
- [x] **Full-Stack Decoupled Architecture**: FastAPI backend + React 19 / TypeScript / Vite frontend.
- [x] **8-Class Civic Issue Taxonomy**: Potholes, road damage, garbage overflow, illegal dumping, water leaks, blocked drains, streetlights, public assets.
- [x] **Explainable Computer Vision**: Deterministic edge density, dark pixel depth, luminance variance, and multi-class probability vectors.
- [x] **5-Factor Priority Scoring Engine**: Weighted multi-criteria calculation across Severity, Safety, Location Risk, Community Impact, and SLA Age.
- [x] **Spherical Haversine Duplicate Detection**: Spatial proximity ($<100\text{m}$), category matching, and non-destructive merge approval workflow.
- [x] **DBSCAN Spatial Hotspot Clustering**: Density clustering identifying localized neighborhood infrastructure failure nodes.
- [x] **Role-Based Municipal Workflow**: Citizen grievance portal vs. Municipal Operations Control Center with departmental assignment (BBMP, BWSSB, BESCOM).
- [x] **Human-in-the-Loop AI Overrides**: Full administrative override controls with immutable audit trail logging.
- [x] **Modern UI/UX**: Dark/Light mode theme engine, reactive floating toasts, accessible WCAG contrast, skeleton shimmers, and photo lightbox inspector.
- [x] **Realistic Demonstration Dataset**: 140+ seeded Bengaluru civic reports with instant one-click reset utility.

## Future Strategic Horizons

### Phase 2: Native Mobile & Edge Inference (Q1 2027)
- **Cross-Platform Mobile Application**: Build native iOS and Android apps using React Native / Flutter with offline-first local SQLite caching.
- **On-Device Edge Vision Models**: Quantize vision models using TensorFlow Lite / ONNX Runtime to execute inference directly on citizen smartphones before upload.
- **Background GPS Telemetry**: Optional background road quality accelerometer vibration logging for participating municipal bus fleets.

### Phase 3: Conversational & Messaging Channels (Q2 2027)
- **WhatsApp & Telegram Municipal Bots**: Enable citizens to report civic defects by forwarding a photo and WhatsApp live location pin without needing to register on a website.
- **Automated Citizen SMS Status Alerts**: Trigger automated SMS updates via Twilio / Gupshup when an issue is assigned, inspected, or resolved.
- **Multilingual Voice Grievance Ingestion**: Support regional audio voice messages (Kannada, Hindi, Tamil, Telugu) transcribed via Whisper.

### Phase 4: Autonomous Municipal Inspection & Drone Feeds (Q3 2027)
- **Dashcam Video Stream Processing**: Mount automated cameras onto municipal garbage collection trucks to continuously scan road surfaces during routine daily routes.
- **Aerial Drone Photogrammetry**: Ingest aerial survey orthophotos following monsoon seasons to calculate lake catchment water levels and major embankment fissures.
- **Automated Work-Order Contractor Dispatch**: Integration with municipal ERP systems (SAP, Oracle Public Sector) to automatically generate contractual purchase orders for approved road repairs.

### Phase 5: Predictive Urban Maintenance (Q4 2027)
- **Infrastructure Deterioration Forecasting**: Graph Neural Networks (GNNs) analyzing historical repair frequency, traffic volume, and monsoon precipitation to predict asphalt failure 3 months before potholes develop.
- **Budget Allocation Decision Optimization**: Linear programming algorithms recommending optimal municipal capital expenditure distribution across wards to maximize citizen satisfaction per rupee spent.
